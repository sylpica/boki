## 2027年度の主要変更と本アプリの対応

| 変更 | 対応 |
|---|---|
| 紙媒体の手形・小切手の廃止に伴い、手形関連の規定をすべて削除 | 受取手形・支払手形・手形の裏書譲渡・割引・小切手振出しを出題しない。科目マスタにも含めない（テストで担保） |
| 「売掛金および買掛金ならびに電子記録債権等」に再編、営業外電子記録債権・債務を明記（2級列） | 電子記録債権・電子記録債務の発生・決済を出題。営業外分は3級列ではないため必須出題に含めない |
| クレジット売掛金に「キャッシュレス決済を含む」と追記 | クレジット・QR決済等の問題を収録 |
| 販売のつど売上原価勘定に振り替える方法を2級から3級へ移行 | 教材L07と問題群（基礎＋派生）を収録 |
| 有形固定資産の除却・廃棄を2級から3級へ移行 | 教材L11と問題群を収録 |
| 定率法（※）を2級から3級へ移行。ただし償却率を示す簡易な出題に限る。保証率・改定償却率は出題しない | 定率法は償却率提示の基本形のみ出題し、問題文にも範囲を明記 |
| 普通預金を区分表に明記 | 現金預金の単元で普通預金・複数口座を扱う |
| リースは3級ではオンバランス処理を求めない。支払家賃・支払地代は従来どおり賃貸借処理で出題 | リース資産の計上問題は出題しない |

## 試験仕様（公式確認済み）

- ネット試験：3題以内、60分、選択式＋入力式。仕訳問題は選択式（プルダウン方式）。
- 金額入力は数字のみ（文字・円マーク等は不正解）。カンマ不要。
- 仕訳の各設問では、各勘定科目の使用は借方・貸方の中でそれぞれ1回ずつ（同じ側で2回使うと不正解）→ 本アプリの採点にも同ルールを実装。
- 2027年4月1日以降の配点：第1問45点・第2問25点・第3問30点、合計100点、合格基準70点以上。
- 電卓は計算機能のみのものを持込可。計算・メモ用紙は会場がA4判2枚とボールペンを用意。
- 採点基準の詳細は非公開のため、本アプリの模試採点は独自基準であり、その旨を画面に明示する。
