## 発見と修正の一覧

### P1（重大）— 全件修正済み
1. **金額が問題文にない解答不能な問題 6問**（gen-base-cash-payment-0009〜0014）: 問題文に金額を追加。
2. **正答科目の誤り 1問**（gen-base-cash-receipt-0003、貸付金回収の相手科目が売上）: 生成分岐の判定条件（「元本」を含むか→「貸付金」を含むか）を修正し、正答を貸付金に是正。
3. **問題文の条件と正答が矛盾する問題 4問**（前払家賃の決算整理）: 支払月が未経過月数と一致するよう問題文を修正（4月1日→7月/8月/10月1日）。
4. **模試採点に公式の重複科目ルール未適用**: 演習採点と共通の `duplicateInvalidatedKeys` を模試採点にも適用。
5. **時間切れ時に自動採点されず確認ダイアログが繰り返し出る**: 時間切れ経路は確認なしで即時採点に変更（手動終了は従来どおり確認付き）。
6. **壊れた形状の保存データでアプリが白画面になる**: migrate で要素単位のサニタイズ（attempts/exams/draft/settings/lessonStages/practiceDraft）を実装。

### P2（中程度）— 修正済み
- 存在しない日付（5月32日等）を含む商品有高帳の問題 7問: 日付生成を圧縮し実在日付のみに。
- 計算要否の誤分類 1問（c3-12、残額の差額計算が必要なのに計算不要扱い）: needsCalc=true に是正し、計算過程とヒントも整合させた。計算除外プールは 272→271問。
- 保存失敗が利用者に伝わらない: 警告バナーを表示。
- Service Worker の配信ラグ: HTMLはネットワーク優先に変更し、キャッシュ名を v2 に更新。
- 通常演習の途中状態・教材の閲覧段階が保存されない（R32）: 自動保存とホームからの再開を実装。
- 模試の所要時間が未記録（R30）: ExamRecord に seconds を追加し、分析画面に表示。本日の学習時間と日次目標の対比も追加（R31）。
- ヒント使用正解が自力正解と同等に算入（R28）: 習熟度・換算正答率で 0.5 換算に変更し、定義を画面に明示。
- 欄単位の正誤が保存されない（R26）: AttemptRecord.fieldResults を保存。

### P3（軽微）— 修正済み／記録
- 電卓が Function() で式を評価 → 安全な再帰下降パーサに置換。
- フォーカス輪郭のライトテーマでのコントラスト不足（2.29:1） → #b35400（約5:1）に変更。ダークテーマにも --focus を追加。
- 教材タブの ARIA（tabpanel/aria-controls）、用語ポップアップの Esc 閉じ・フォーカス移動、模試タイマーの role=timer、.linklike のタッチターゲット拡大、仕訳表の横スクロールラッパー。
- PWA アイコンが SVG のみ → PNG 192/512 と apple-touch-icon（180px）を生成したが、**GitHubコネクタの配信がUTF-8テキスト専用でバイナリを送れず、公開サイトと不整合になるため取り下げ**。未解決事項として記録する。
- テーマ auto が OS の切替に追随しない → matchMedia リスナーで動的追随。
- 教材 L08 の電子記録債権「譲渡」記述が3級範囲と誤解される表現 → 譲渡・割引は2級範囲と明記に修正。L12 の「仮払法人税等」（科目マスタにない科目名）→ 精算の記述に修正。辞典「ファクタリング」に2級の論点・参考である旨を明記。

## 未解決事項（残置と理由）

| 項目 | 重大度 | 内容と理由 |
|---|---|---|
| R05/R23 | P2 | 独立問題274問（総数1,030問）。仕様の「独立1,000問以上」は目安であり、派生を独立と偽る水増しはしない。独立問題の追加作成は別途の作問作業として切り分け可能。 |
| R20 | P2 | 操作型シミュレーション未実装。静的な仕訳例表のみ。会計的正確性を優先し、未検証の対話機能は追加しない。 |
| R37 | P2 | 精算表・財務諸表は表描画ではなく解答欄リスト形式。行列構造の訓練としては限定的。 |
| R07/R19/R33 | P3 | 科目名タイプ入力形式、問題文内用語リンク、情報密度調整は未実装。 |
| 実機検証 | P2 | iPhone実機での表示・オフライン再読込・375px幅の実測は未実施（確認用ブラウザの制約）。ユーザー側の実機確認が実質的な門番になる。 |
| PWAアイコン | P3 | PNGアイコン（iOSホーム画面用）を配信できない。GitHubコネクタのファイル配信がUTF-8専用でバイナリ非対応のため。SVGアイコンのみで運用し、解消にはバイナリ配信手段（別ホスト等）が必要。 |
