# コンテンツ事実監査（BOKI_CONTENT_FACTCHECK）— 2026-11-11

方法：アプリ自身のテスト（src/app.test.ts）を使わず、独立スクリプトでデータファイルを直接読み、全件を再計算・照合した。公式資料は日本商工会議所の2027年度確定出題区分表（2026-07-31公表）、2027年度3級配点の公式発表（2026-09-25）、ネット試験の案内に基づく（前回監査で一次資料を確認済みの内容を、本ラウンドの照合基準として再使用）。

## 制度との一致

- 配点：第1問45点・第2問25点・第3問30点、合計100点、60分、合格基準70点。模試の構成（15問×3点、15点+10点、30点）と SECTION_MAX はこの値と一致。旧配点（45/20/35等）の残存なし。
- 2027年度改定：紙の手形・小切手の廃止に伴う手形関連は出題しない。受取手形・支払手形・小切手・裏書・割引が正答科目として使われている問題は0件。
- 3級へ移行した論点（定率法は償却率提示の基本形のみ、販売のつど売上原価振替、有形固定資産の除却・廃棄）は収録され、定率法は全件「期首帳簿価額×提示された償却率」の形で、保証率・改訂償却率を使う計算は0件。
- 2級列のみの論点（銀行勘定調整表、仕入割戻、電子記録債権の譲渡・割引、営業外電子記録債権・債務など12語で照合）が正答として使われている問題は0件。出現はすべて「範囲外である旨の説明」の中のみ。

## 採点の事実関係

- 仕訳の同一科目の同側重複使用は不正解（公式の解答注意）— 演習・模試で共通ロジックを適用し、テストで担保。
- 金額は数字のみ（公式の解答注意）— 本ラウンドで採点の契約を統一し、カンマ・円記号等を含む入力は不正解とした。
- 模試の部分点の細部は公式非公開。本アプリは「欄の正誤に応じた按分（全欄正解のみ満点）」という独自方式で、開始画面と結果画面にその旨を明示する。旧方式の記録は gradingVersion で区別し、得点を書き換えない。
