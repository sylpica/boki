# boki

日商簿記検定3級（2027年度以降・ネット試験対応）の無料・ログイン不要の学習Webアプリです。
日本商工会議所とは無関係の独自アプリで、問題・教材はすべて独自作成です（公式サンプル問題の転載はしていません）。

公開URL: https://sylpica.github.io/boki/

## 主な機能

- 教材：16レッスン、各レッスンに概要・詳細・専門的解説・実務例の4段階解説
- 辞典：勘定科目・専門用語（検索・分類・関連教材へのリンク）
- 問題演習：本試験形式のみ（仕訳はプルダウン科目選択＋金額入力、帳簿・試算表・精算表・財務諸表の完成）
  - 計算問題除外モード（計算不要の問題だけを出題）
  - 毎回シャッフル＋直近出題の回避、段階的ヒント
- 模擬試験：固定10回分とランダム生成。60分・100点（第1問45点／第2問25点／第3問30点）、合格基準70点・目標95点
- 復習・成績分析：単元別正答率と習熟度、模試の推移、誤答の優先復習
- PWA：オフライン対応、学習データは端末内（localStorage）に自動保存

## 開発

```sh
npm install
npm run dev
npm test        # 問題データの貸借一致・科目検証・採点・シャッフル・模試構成の自動テスト
npm run build   # dist/ に出力（base: /boki/）
```

出題範囲の対応表は `docs/SYLLABUS_COVERAGE.md` を参照してください。
