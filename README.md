# boki

日商簿記検定3級（2027年度以降・ネット試験対応）の無料・ログイン不要の学習Webアプリです。
日本商工会議所とは無関係の独自アプリで、問題・教材はすべて独自作成です（公式サンプル問題の転載はしていません）。

公開URL: https://sylpica.github.io/boki/

## 主な機能

- 教材：16レッスン、各レッスンに概要・詳細・専門的解説・実務例の4段階解説。主要レッスンには数値検証済みの図表（5要素・T勘定・帳簿の流れ・貸借対照表・損益計算書）
- 辞典：勘定科目・専門用語（検索・分類・関連教材へのリンク）
- 単語帳：辞典から作る151枚のカード。表面／裏面どちらからでも開始でき、自己評価による復習予定・ブックマーク・再開に対応（問題演習とは別の記憶モード）
- 問題演習：本試験形式のみ（仕訳はプルダウン科目選択＋金額入力、帳簿・試算表・精算表・財務諸表の完成）
  - 計算問題除外モード（計算不要の問題だけを出題。教材・復習を含む全入口に適用）
  - シャッフルON/OFF・再シャッフル＋直近出題の回避、段階的ヒント
  - 金額は公式の解答注意どおり数字のみで判定（カンマ・円記号を含む入力は不正解）
- 模擬試験：固定10回分とランダム生成。60分・100点（第1問45点／第2問25点／第3問30点）、合格基準70点・目標95点。採点は欄の正誤に応じた按分（全欄正解のみ満点）で、公式非公開の細部はアプリ独自の近似
- 復習・成績分析：単元別正答率と習熟度、模試の推移、誤答の優先復習
- データ保護：学習データの書き出し・取り込み、破損データの自動退避
- PWA：オフライン対応、学習データは端末内（localStorage）に自動保存

## 開発

```sh
npm install
npm run dev
npm test        # 問題データの貸借一致・科目検証・採点・シャッフル・模試構成の自動テスト
npm run build   # dist/ に出力（base: /boki/）
```

出題範囲の対応表は `docs/SYLLABUS_COVERAGE.md` を参照してください。
